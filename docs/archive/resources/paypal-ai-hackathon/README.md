# PayPal AI Hackathon resource pack

Captured October 7, 2026 from the [official Devpost resources page](https://paypalaihackathon.devpost.com/resources).

The pack turns the page into a working index for a fresh idea search. It records the direct links, what each resource is useful for, the access or trial notes shown by the sponsor pages, and the official problem areas suggested by PayPal.

## Start here

1. [Resource inventory](inventory.md) — every first-party resource link grouped by purpose.
2. [Core PayPal map](core-paypal.md) — the shortest route from sandbox payment to event-driven product.
3. [AI and agent map](ai-agent-resources.md) — PayPal's AI tooling plus optional agent infrastructure.
4. [Sponsor tools](sponsor-tools.md) — the 10 sponsor offerings and when each is worth adding.
5. [Inspiration and reset worksheet](inspiration.md) — the five official tracks, translated into an idea filter.
6. [Idea deep dive](idea-deep-dive.md) — everyday payment problems mapped to AI actions and PayPal capabilities.
7. [Source audit](source-audit.md) — capture date, redirects, and links that require browser verification.

## Working rule for the reset

Choose the payment problem first. Add one PayPal capability and one AI action that changes the transaction experience. Keep the demo to one complete path: input, reviewed AI decision, PayPal action, and visible result.

Job’z remains archived at [ideas/jobz](../../ideas/jobz/README.md). The rescue donation concept remains saved at [ideas/rescue-giving](../../ideas/rescue-giving/README.md), but neither is the default direction.

## Hackathon timing

The resources page lists the deadline as **November 12, 2026 at 12:00pm PST**. Confirm the live Devpost page before submission because dates and links can change.
